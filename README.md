# 健康内容中台（带登录 · 集中式内容库）

管理员在后台手动上传 **视频 / 封面 / 文案**，保存后自动同步到前端展示页；带登录与权限：
**管理员（你）** 可上传内容、增删「查看账号」；**查看者** 登录后只能浏览公司内容库。

---

## 一、功能一览

- 登录门禁：未登录看不到任何内容。
- 角色：`管理员`（上传 / 编辑 / 删除 / 账号管理）、`查看者`（只读浏览）。
- 上传：视频文件、封面图、标题、分类、三类标签、摘要、正文；支持视频链接。
- 展示：6 大内容库 + 标签筛选（内容标签 30 个 / 内容形态 / 用户旅程）+ 搜索 + 详情弹窗内播放视频。
- 数据：内容与上传文件存服务端（`DATA_DIR`），所有登录用户看到同一份。

## 二、默认账号

- 管理员用户名固定为 **`admin`**，密码为部署时填写的 `ADMIN_PASSWORD`（未设置时默认 `admin123`，请务必修改）。
- 查看账号由管理员在页面右上角「👥 账号管理」里添加。

## 三、部署成公开网址（Render，约 3 分钟）

1. 注册/登录 GitHub，新建一个仓库（可私有），把本 `content-platform` 文件夹里的内容推上去。
2. 打开 [render.com](https://render.com) 注册/登录 → 顶部 **New → Blueprint** → 选这个仓库。
3. Render 读到 `render.yaml` 自动建站；在弹出页面为 `ADMIN_PASSWORD` 填一个你自己的管理员密码 → 点 **Apply / Create**。
4. 等 1~2 分钟构建完成，Render 给你一个公开网址（形如 `https://xxx.onrender.com`）——那就是发给别人的链接。

> 持久化提示：Render 免费实例的磁盘是临时的，重新部署后上传的文件/内容可能重置。要长期保存，升级到付费实例并启用 `render.yaml` 里注释的持久盘（挂到 `/var/data`）。

## 四、日常使用步骤

**作为管理员（你）：**
1. 打开网址 → 用 `admin` + 你设置的密码登录。
2. 右上角 **✏️ 编辑模式** → **＋ 新建内容** → 填标题、选分类、勾标签，**选择本地视频 + 封面图**、填文案 → 保存。保存后前端立即出现该条内容。
3. 右上角 **👥 账号管理** → 输入「账号名 + 密码」→ **＋ 添加查看账号**。把网址和账号发给对方即可。
4. 需要改管理员密码：同一弹窗下方的「修改管理员密码」。

**作为查看者（其他人）：**
1. 打开同一个网址 → 用管理员给的账号密码登录 → 浏览、按标签筛选、点开卡片看视频。看不到上传/账号管理入口。

## 五、本机预览（可选，仅调试用）

```bash
cd content-platform
npm install
ADMIN_PASSWORD=admin123 node server.js
# 浏览器打开 http://localhost:3000
```

## 六、技术栈

Node.js + Express，数据用 JSON 文件（`DATA_DIR/contents.json`、`users.json`），上传文件存 `DATA_DIR/uploads`。
登录用 HMAC 签名令牌 + scrypt 密码哈希，无第三方数据库依赖。
